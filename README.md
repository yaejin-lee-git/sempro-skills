# 셈프로 회계 스킬 (Claude Code 플러그인)

## jageum: 지점별 자금수지보고

위하고 분개장, 통장 잔액(나스 원자료)과 지난달 자금수지보고를 읽어 이번 달 보고서를 만듭니다.

- 지난달 보고서의 양식, 수식, 지점별 칸은 그대로 두고 값만 채웁니다
- 자금수지 줄: 분개장의 보통예금 줄 (프로젝트 = 분류)
- 계좌표: 전일과 통장 시재는 통장 잔액, 입금과 출금은 분개장. MMF와 신탁은 통장 기준으로 따로 합산
- 점검표: 장부 잔고와 통장 시재 차이, 프로젝트 빈 줄, 전표 처리 전 통장 거래, 분류가 어긋나 보이는 줄
- 비고: Claude가 지난달 말투로 초안
- 통합: 전 지점 시재 합계

### 설치 (Claude 앱 Code 탭 또는 Claude Code)
GitHub 계정은 필요 없습니다.
```
/plugin marketplace add yaejin-lee-git/sempro-skills
/plugin install jageum@sempro
```
처음 부르면 Claude가 설정 인터뷰를 합니다: 실행 도구(uv) 설치, 나스 폴더 찾기, 저장 가능 여부, 담당 지점, 회사 이름. 설정은 PC마다 `~/.jageum/config.json`에 저장됩니다.

### 쓰는 말
- `자금수지 처음 설정해 줘`
- `자금 확정했어. 2026년 10월 본점 자금수지 해줘`
- `위하고에서 고쳤어. 다시 해줘`
- `10월 자금수지 통합 해줘`

### 폴더 규칙 (나스 기준, 설정 때 자동으로 찾음)
| 무엇 | 위치 |
|---|---|
| 지점 보고서 | `<지점별 자금수지보고 폴더>/<지점 폴더>/` 지난달 파일 옆 |
| 원자료 | `<데이터 자동수집 폴더>/<연>/<연-월>_마감분/자금수지/<지점 폴더>/` 분개장, 통장거래 엑셀 |
| 통합 | `<지점별 폴더의 상위>/통합 자금수지보고/<연>/` |

이미 담당자가 만든 보고서가 있으면 덮지 않고 이름 끝에 `(셈프로)`를 붙여 저장합니다.

업데이트: `/plugin marketplace update sempro`
